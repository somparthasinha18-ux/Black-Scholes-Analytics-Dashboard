# Black-Scholes Analytics Dashboard

A professional options pricing and quantitative finance dashboard built using Flask, Plotly, and the Black-Scholes Model.

## 🚀 Live Demo

🔗 https://nejewjpfew.pythonanywhere.com

## 📂 GitHub Repository

🔗 https://github.com/somparthasinha18-ux/Black-Scholes-Analytics-Dashboard

## Features

- Black-Scholes Call & Put Pricing
- Option Greeks (Delta, Gamma, Theta, Vega, Rho)
- Implied Volatility Calculator
- Volatility Smile Visualization
- Sensitivity Analysis
- Monte Carlo Option Pricing
- Monte Carlo Path Simulation
- Options Strategy Payoff Charts
- Yahoo Finance Live Market Data Integration
- Interactive Plotly Dashboards

## Tech Stack

- Python
- Flask
- Plotly
- NumPy
- Pandas
- Yahoo Finance API
- HTML/CSS
- Bootstrap
