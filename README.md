# Black-Scholes Analytics Dashboard

A professional quantitative finance platform for option pricing, risk analysis, volatility modeling, and Monte Carlo simulation built using Flask, Plotly, and the Black-Scholes framework.

## Features

* Black-Scholes Call & Put Pricing
* Option Greeks (Delta, Gamma, Theta, Vega, Rho)
* Implied Volatility Calculator
* Volatility Smile Visualization
* Sensitivity Analysis
* Monte Carlo Option Pricing
* Monte Carlo Path Simulation
* Options Strategy Payoff Analysis
* Yahoo Finance Market Data Integration
* Interactive Plotly Visualizations

## Tech Stack

* Python
